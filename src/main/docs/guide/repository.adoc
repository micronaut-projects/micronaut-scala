Source code, issues and pull requests are available in the
https://github.com/{githubSlug}[Micronaut Scala repository].

The repository separates shared sources from compiler-specific builds:

* `inject-scala` contains the compiler plugin implementation.
* `inject-scala-test` contains the compiler test harness and parity tests.
* `inject-scala-compiler` publishes the primary compiler plugin, and
  `inject-scala-compiler-lts` builds the same sources for Scala 3.3.9.
* `inject-scala-test-compiler` publishes the test harness and runs the compiler
  integration tests.
* `runtime-scala` contains converters and serialization support.
* `test-suite-scala` contains the main guide examples. The `test-suite-scala-data`,
  `test-suite-scala-serde` and `test-suite-scala-openapi` modules cover those
  integrations.
* `micronaut-scala-bom` manages the published artifact versions.

See `CONTRIBUTING.md` in the repository for the JDK requirements, build commands
and contribution process.
