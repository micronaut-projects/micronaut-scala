To use Micronaut from Scala, add the compiler plugin to your build and the
Scala runtime support to your application's runtime dependencies. Use JDK 25
and choose a plugin artifact that matches your full Scala compiler version.

== Add the dependencies

For a Gradle application using Scala 3.10.0, add these entries to your
`dependencies` block:

[source,kotlin]
----
scalaCompilerPlugins("io.micronaut.scala:micronaut-inject-scala_3.10.0:1.0.0-SNAPSHOT")
runtimeOnly("io.micronaut.scala:micronaut-runtime-scala:1.0.0-SNAPSHOT")
----

`micronaut-inject-scala_3.10.0` runs during compilation and generates the classes
Micronaut needs to create and inject your beans. `micronaut-runtime-scala`
provides converters and serialization support for Scala types at runtime.

WARNING: Keep the compiler plugin off the application runtime classpath. Its jar
bundles Micronaut and ASM classes that can conflict with the application's own
dependencies.

See <<buildTools, Build Tools>> for a fuller Gradle configuration and examples
for Maven, sbt and Mill. Adding the plugin as an ordinary dependency does not
register it with the Scala compiler.

== Define and use a bean

Define a dependency as a bean with `@Singleton`:

snippet::io.micronaut.docs.helloworld.Translator[source=main,language=scala,tags=clazz]

Then declare it as a constructor parameter in another bean:

snippet::io.micronaut.docs.helloworld.GreetingService[source=main,language=scala,tags=clazz]

Micronaut supplies `Translator` when it creates `GreetingService`. In an
application context, calling `getBean(classOf[GreetingService]).greet("Scala")`
returns `Hello, Scala`.

See <<concepts, Micronaut for Scala Developers>> for more about bean creation,
qualifiers and the other framework features.

== Match the compiler version

The suffix `_3.10.0` is the full Scala compiler version. Do not shorten it to
`_3` or use it with a different compiler release. See
<<introduction, Supported versions>> for the available variants.

The examples use the development version `1.0.0-SNAPSHOT`. When using a
released version, replace that version in both dependencies.
