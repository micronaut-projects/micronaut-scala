Register Micronaut Scala as a Scala compiler plugin. The configuration depends
on your build tool, but the artifact name must always match the full Scala
compiler version. The examples below use Scala 3.9.0 and JDK 25.

== Gradle

Use Gradle's `scalaCompilerPlugins` configuration for the plugin:

[source,kotlin]
----
plugins {
    scala
}

repositories {
    mavenCentral()
}

java {
    toolchain {
        languageVersion = JavaLanguageVersion.of(25)
    }
}

dependencies {
    implementation("org.scala-lang:scala3-library_3:3.9.0")
    implementation("io.micronaut:micronaut-context:5.2.2")

    scalaCompilerPlugins("io.micronaut.scala:micronaut-inject-scala_3.9.0:1.0.0-SNAPSHOT")
    runtimeOnly("io.micronaut.scala:micronaut-runtime-scala:1.0.0-SNAPSHOT")
}

tasks.withType<ScalaCompile>().configureEach {
    options.release.set(25)
    scalaCompileOptions.additionalParameters.add("-J--add-modules=java.compiler")
}
----

The `java.compiler` module provides the `javax.lang.model` APIs used by
Micronaut processing code. Pass `-J--add-modules=java.compiler` to make it
available in the compiler process.

The repository's `ScalaGradlePluginFunctionalSpec` exercises plugin loading and
bean generation through a separate Gradle build, using local jar files as
dependencies.

== Maven

Register the compiler plugin in `scala-maven-plugin`'s `compilerPlugins`
configuration. Add runtime support as an application dependency:

[source,xml]
----
<properties>
  <scala.version>3.9.0</scala.version>
  <micronaut.scala.version>1.0.0-SNAPSHOT</micronaut.scala.version>
</properties>

<dependencies>
  <dependency>
    <groupId>org.scala-lang</groupId>
    <artifactId>scala3-library_3</artifactId>
    <version>${scala.version}</version>
  </dependency>
  <dependency>
    <groupId>io.micronaut.scala</groupId>
    <artifactId>micronaut-runtime-scala</artifactId>
    <version>${micronaut.scala.version}</version>
    <scope>runtime</scope>
  </dependency>
</dependencies>

<build>
  <plugins>
    <plugin>
      <groupId>net.alchim31.maven</groupId>
      <artifactId>scala-maven-plugin</artifactId>
      <configuration>
        <args>
          <arg>-J--add-modules=java.compiler</arg>
        </args>
        <compilerPlugins>
          <compilerPlugin>
            <groupId>io.micronaut.scala</groupId>
            <artifactId>micronaut-inject-scala_3.9.0</artifactId>
            <version>${micronaut.scala.version}</version>
          </compilerPlugin>
        </compilerPlugins>
      </configuration>
    </plugin>
  </plugins>
</build>
----

This fragment assumes the rest of the application's Micronaut dependencies and
the Scala Maven plugin version and compile executions are configured.

== sbt

The example names the complete artifact ID explicitly:

[source,scala]
----
scalaVersion := "3.9.0"

libraryDependencies ++= Seq(
  "io.micronaut" % "micronaut-context" % "5.2.2",
  "io.micronaut.scala" % "micronaut-runtime-scala" % "1.0.0-SNAPSHOT" % Runtime
)

addCompilerPlugin(
  "io.micronaut.scala" % "micronaut-inject-scala_3.9.0" % "1.0.0-SNAPSHOT"
)

javacOptions ++= Seq("--add-modules", "java.compiler")
----

If you use sbt's `cross` dependency notation instead, select `CrossVersion.full`.
The default binary-version suffix `_3` does not identify a published plugin.

== Mill

Add the plugin to `scalacPluginIvyDeps`, using its full artifact ID:

[source,scala]
----
object app extends ScalaModule {
  def scalaVersion = "3.9.0"

  def ivyDeps = Agg(
    ivy"io.micronaut:micronaut-context:5.2.2",
    ivy"io.micronaut.scala:micronaut-runtime-scala:1.0.0-SNAPSHOT"
  )

  def scalacPluginIvyDeps = Agg(
    ivy"io.micronaut.scala:micronaut-inject-scala_3.9.0:1.0.0-SNAPSHOT"
  )

  def scalacOptions = Seq("-J--add-modules=java.compiler")
}
----

When using Mill's cross-version notation instead of an explicit suffix, use the
full-cross `:::` form.

NOTE: The repository tests the Gradle integration. The Maven, sbt and Mill
fragments are not exercised here. If compilation produces no bean definitions,
see <<troubleshooting, Troubleshooting>>.
