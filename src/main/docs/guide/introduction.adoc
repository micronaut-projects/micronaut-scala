Micronaut Scala provides the Scala 3 compiler plugin and the Scala-specific
processing model that integrates Scala sources with Micronaut Framework.

The implementation is maintained separately from Micronaut Core. Core
provides the language-neutral processing and runtime extension points, while
this project owns the Scala compiler integration, Scala element model, and
Scala-specific type handling.

== Supported versions

Two Scala 3 LTS lines are supported, built from the same sources and published
as separate artifacts. The compiler plugin API is not binary compatible across
compiler releases, so the compiler version is part of the artifact name:

* `io.micronaut.scala:micronaut-inject-scala_3.9.0` — current LTS
* `io.micronaut.scala:micronaut-inject-scala_3.3.8` — previous LTS
* `io.micronaut.scala:micronaut-inject-scala-test_3.9.0`
* `io.micronaut.scala:micronaut-runtime-scala` — application-side support, not
  crossed with the compiler version

Selecting the wrong one does not fail gracefully: the 3.9.0 plugin loaded into
the 3.3.8 compiler throws from inside the plugin phase and generates nothing.
Match the artifact to the compiler exactly.

The repository version is independent of the Micronaut Core version. The
initial development version is `1.0.0-SNAPSHOT`.

== What is included

The compiler plugin connects Scala compiler phases to Micronaut compile-time
visitors. The Scala processing model supports bean definitions, injection,
introspection, AOP, configuration properties, annotation metadata, Scala
collections, `Option`, `BeanRegistration`, and Scala 3 enum lookup.

Scala 2 is not currently supported. GraalPy is not required by the Scala
compiler plugin or its test harness.

If you are new to Micronaut, <<concepts, Micronaut for Scala Developers>>
explains dependency injection, configuration, introspections, serialization and
AOP from the beginning, in Scala. For the wider framework documentation, see the
Micronaut Framework user guide.
