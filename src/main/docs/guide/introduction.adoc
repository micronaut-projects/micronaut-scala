Micronaut Scala provides the Scala 3 compiler plugin and the Scala-specific
processing model that integrates Scala sources with Micronaut Framework.

The implementation is maintained separately from Micronaut Core. Core
provides the language-neutral processing and runtime extension points, while
this project owns the Scala compiler integration, Scala element model, and
Scala-specific type handling.

== Supported versions

The initial supported compiler is Scala 3.3.8. The compiler plugin API is not
binary compatible across all Scala compiler releases, so the compiler version
is part of the published artifact name. The initial artifacts are:

* `io.micronaut.scala:micronaut-inject-scala_3.3.8`
* `io.micronaut.scala:micronaut-inject-scala-test_3.3.8`

The repository version is independent of the Micronaut Core version. The
initial development version is `1.0.0-SNAPSHOT`.

== What is included

The compiler plugin connects Scala compiler phases to Micronaut compile-time
visitors. The Scala processing model supports bean definitions, injection,
introspection, AOP, configuration properties, annotation metadata, Scala
collections, `Option`, `BeanRegistration`, and Scala 3 enum lookup.

Scala 2 is not currently supported. GraalPy is not required by the Scala
compiler plugin or its test harness.

For the user-facing Micronaut Framework usage guide and tested application
examples, see the Scala language-support documentation in the Micronaut Core
repository.
