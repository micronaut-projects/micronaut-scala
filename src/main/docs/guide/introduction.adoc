Micronaut Scala lets you use Micronaut Framework from Scala 3. Its compiler
plugin generates bean definitions, introspections and AOP proxies from your
Scala classes during compilation.

The plugin adapts Scala declarations to Micronaut's compile-time APIs. Micronaut
Core provides the shared processing and runtime infrastructure; this project
provides the Scala compiler integration and runtime support for Scala types.

== Supported versions

Scala 3.9.0 is the primary LTS compiler release. The build also supports
Scala 3.3.9 (previous LTS) and Scala 3.10.0 (non-LTS). Each compiler version
has its own plugin artifact:

* `io.micronaut.scala:micronaut-inject-scala_3.9.0`
* `io.micronaut.scala:micronaut-inject-scala_3.3.9`
* `io.micronaut.scala:micronaut-inject-scala_3.10.0`

Choose the artifact that exactly matches your Scala compiler version. Compiler
plugin APIs can change between releases, so using a different version can fail
during compilation.

The test harness is published as
`io.micronaut.scala:micronaut-inject-scala-test_3.9.0`. Runtime support is
published as `io.micronaut.scala:micronaut-runtime-scala` and does not have a
compiler-version suffix.

Micronaut Scala has its own version, independent of Micronaut Core. The current
development version is `1.0.0-SNAPSHOT`. The build requires JDK 25.

== What is included

The integration supports dependency injection, bean introspection, AOP,
configuration properties and annotation metadata. Runtime support includes
converters for Scala collections and `Option`, along with Micronaut
Serialization support for collections, `Option` and Scala 3 enums.

Scala 2 is not supported.

Start with <<quickStart, Quick Start>> to configure the plugin. If you are new
to Micronaut, <<concepts, Micronaut for Scala Developers>> introduces the main
framework features with Scala examples.
